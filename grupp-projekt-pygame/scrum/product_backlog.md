# PRODUCT BACKLOG

- Som spelare vill jag kunna gå och hoppa så att jag kan ta mig igenom banan.

- Som spelare vill jag kunna kollidera med mark och väggar/hinder så att jag inte ramlar/går igenom världen.

- Som spelare vill jag möta en enkel fiende som första utmaning.

- Som spelare vill kunna stara, pausa och stänga va spelet så att jag har kontroll över sessionen.

- Som spelare vill jag spela banor som blir svårare och svårare.

- Som spelare vill jag kunna möta olika fiender för lite mer variation.

- Som spelare vill jag se olika teman på banorna.

- Som spelare vill jag samla mynt/pengar.

- Som spelare vill jag att spelet ska ha musik och ljudeffekter.

- Som spelare vill jag se animationer på spelare och fiender.

- Som spelare vill jag kunna dubbelhoppa.

- Som spelare vill jag hitta hemliga områden så att jag får belöningar för att utforska spelet.

- Som spelare vill jag ha en scoreboard där jag kan se poäng.
