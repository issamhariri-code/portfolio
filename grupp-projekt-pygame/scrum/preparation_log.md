# Förberedelser inför Sprint 1

**Datum:** 01-02 December 2024  
**Ansvarig:** Ikaros (Scrum Master)

## Översikt
Dokumentation av allt förberedelsearbete som gjordes innan första Daily Stand-up och sprint start.

---

## Genomförda aktiviteter

### GitHub Projects Setup (01 Dec)
**Vad gjordes:**
- Skapade projekt "Minil-Tech project" i GitHub
- Konfigurerade board med tre kolumner:
  - Todo (grönt) - "This item hasn't been started"
  - In progress (gult) - "This is actively being worked on"
  - Done (lila) - "This has been completed"
- Konfigurerade "Estimate" field för poänguppskattning

**Resultat:** Fungerande Scrum Board redo för teamet

**Tidsåtgång:** ~30 minuter  


---

### Initial Todo-lista (02 Dec)
**Vad gjordes:**
Skapade fyra grundläggande uppgifter för projektstart:
1. Skapa projektstuktur med mappar (assets, src, tests, images)
2. Skapa requirements.txt och dokumentera installation
3. Sätta upp grundläggande README.md med instruktioner
4. Skapa main.py med pygame-fönster och start moduler

**Resultat:** Todo-kolumnen fylld med konkreta uppgifter för teamet att börja med

**Tidsåtgång:** ~45 minuter (inklusive planering och formulering)  


---

### Daily Stand-up förberedelser (01 Dec)
**Vad gjordes:**
- Forskade om Scrum Master-rollen och Daily Stand-up format
- Skapade mall för `daily0212.md` med:
  - Standardstruktur för dokumentation
  - Tre frågor per teammedlem
  - Plats för Scrum Board skärmdump
  - Sektion för anteckningar
- Förberedde cheat sheet med:
  - Mötesagenda (15 min)
  - Vanliga situationer och hur man hanterar dem
  - Tips för att hålla tiden
  - Checklista

**Resultat:** Komplett förberedelse för att leda första Daily Stand-up

**Tidsåtgång:** ~1 timme  


---

### Scrum Master rollförståelse (01 Dec)
**Vad gjordes:**
- Studerade Scrum Master-rollen
- Förstod skillnaden mellan att facilitera vs. leda
- Lärde mig hur man håller möten inom tidsgräns
- Planerade hur man hanterar vanliga situationer

**Resultat:** Redo att facilitera första Daily Stand-up professionellt

**Tidsåtgång:** ~30 minuter
