# Source Code (src)

Denna mapp innehåller spelets centrala Python-källkod.

Filer:

- **`main.py`**  
  Startar spelet, initierar Pygame och kör huvudloopen.

- **`player.py`**  
  Hanterar spelarens rörelser, input, fysik och kollisioner.

- **`function.py`**  
  Innehåller hjälpfunktioner som används av olika delar av spelet.

- **`tests/`**  
  Enkla tester för att verifiera att funktioner och moduler fungerar som avsett.

Det är denna mapp som utgör spelets kärna.
