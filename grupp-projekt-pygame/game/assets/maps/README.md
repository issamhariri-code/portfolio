# Maps

Denna mapp innehåller spelkartor.

Kartfiler används av spelet för att definiera banornas layout, hinder och objekt. Dessa filer laddas in av level-systemet när spelet startar eller byter nivå.

Vanliga format:
- `.tmx` (Tiled-kartor)
- JSON-baserad kartdata
- Anpassade tileset-referenser

Strukturera kartor efter nivå eller område vid behov.
