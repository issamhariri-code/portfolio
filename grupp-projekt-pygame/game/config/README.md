# Config

I denna mapp ligger konfigurationsfiler.

Exempel på innehåll:
- `settings.json` – spelinställningar (storlek, hastighet, färger)
- `config.ini` – konfigurationsvärden som används mellan moduler
- `constants.py` – globala spelkonstanter

Förvara **ALDRIG** känslig data (lösenord, API-nycklar) här.
