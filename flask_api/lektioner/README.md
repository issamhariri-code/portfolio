# Lektionsövningar

Material från lektion 1, 2, 3, 4 och 6. Delar av vissa uppgifter är ofärdiga.

Installera miljön enligt [Flask-guiden](../README.md). För lektion 6:
```bash
cd lektion_6
python -m flask --app application.app run
```

Lektion 6 har äldre lärartester som förutsätter en separat server på port 5000, externa API:er och färdigställda extrauppgifter. De ingår inte i de vanliga testerna för examinationsprojektet och ElprisApp.
