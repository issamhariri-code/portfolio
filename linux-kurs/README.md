# Linuxkurs

Kursanteckningar och shellövningar, tidigare i repot `linux-kurs`.

- [ovningsuppgifter/](ovningsuppgifter/) – anteckningar och lösningar.
- [lektionsarbete/](lektionsarbete/) – lektionsfiler och kommandotester.
- [script/](script/) – enkla Bash-skript.

Vissa övningar använder Ubuntu-filer som `/usr/share/hunspell/sv_SE.dic` och behöver motsvarande paket installerade.
