# Pokémonspel

Menybaserat terminalspel med strider och statistik. Kräver Python 3.10 eller senare, utan extra paket.

Kör från repots rot:
```bash
python3 python/projekt/pokemon/main.py
```

Menyval 5 sparar resultat i `data/matches.json`, relativt programmets plats. Filen innehåller tidigare exempelresultat.
