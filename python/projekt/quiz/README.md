# Quizgenerator

Skapar 35 slumpade quiz med 50 frågor vardera om USA:s delstater och huvudstäder, samt facit.

Kör från repots rot:
```bash
python3 python/projekt/quiz/src/randomQuizGenerator.py
```

Utdata sparas i `quiz_questions/` och `quiz_answers/` i den här projektmappen. Körningen skriver över tidigare quiz. Ett exempel av varje typ finns i Git; övriga genererade filer ignoreras.
