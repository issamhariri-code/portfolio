# Skript

- [ikaros-script/](ikaros-script/) – anpassad Bash-prompt med ursprunglig dokumentation.
- [create_daily_standup.sh](create_daily_standup.sh) – skapar en Scrum-mall i `scrum/daily-standups/` i repots rot. Mallen innehåller deltagarnamn från det ursprungliga grupparbetet.

```bash
bash scripts/create_daily_standup.sh
```

En befintlig fil för samma dag skrivs inte över.
